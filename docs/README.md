## Cara Membaca Dokumentasi

Setiap file dokumentasi berisi:
- **Tujuan** — apa yang dicapai di step ini
- **File yang dibuat/diubah** — daftar lengkap semua file
- **Penjelasan teknis** — cara kerja tiap komponen
- **Skema database** — tabel dan kolom yang terlibat
- **Cara menjalankan** — perintah artisan dan langkah verifikasi
- **Troubleshooting** — masalah yang pernah ditemui dan solusinya
